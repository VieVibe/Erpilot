# 创建语义候选：程序定位与真实供应商探针

日期：2026-11-02。用户授权继续优化并允许真实模型验证。
本批先实测已存在的创建候选链路；发现基础输出问题后优先修复，已有草稿语义修改预览仍待后续。
默认仍为 off，没有修改 .env 或正式数据库，也没有新增业务写入权限。

## 实现

- 新增严格模型输出结构 QuoteCreateProposal：唯一原文由程序精确定位为 Unicode 区间。
  重复原文必须给出明确位置，错误位置不自动修正；不存在、外来消息、半边位置、布尔位置均拒绝。
  定位后继续使用原严格 CreateProposal、金额/件数/引文作用域/重叠核验和真实目录绑定。
  持久化仍是完整 SourceSpan，旧预览继续由原契约复核。
- 模型协议 order-create-proposal-2，提示版本 order-create-proposal-prompt-4。
  明确客户与备注的对象结构、金额证据必须含人民币单位且不含“预算”前缀、未解释片段不能重叠或引用整条消息。
  不增加格式修复请求，也不放宽金额或重复来源核验。
- 新增 `python -m evals.intent_semantic_live --output <新目录> --limit <原币种估价上限>`。
  该命令显式使用 .env 的模型与已确认费率，默认最多五次请求、每次 45 秒、SDK 不自动重试。
  独立 SQLite 目录、预算及原始输出均单次使用，重复目录拒绝；不会确认表单或保存草稿。
  后续预算耗尽的创建样例明确记为 not_run_budget；条件/旧草稿保护仍检查且不能发请求。
