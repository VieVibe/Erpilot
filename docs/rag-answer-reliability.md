# RAG 证据充分性与回答可靠性

2026-10-19。承接真实检索实验中“相关主题片段缺少实际答案”的失败，不调整已有 36 条检索测试集或 0.57 默认阈值。

后续已增加本轮检索绑定的结构化选证和程序渲染，以及可中断的分段验收。当前行为见[结构化答复与续跑契约](resumable-grounding-evaluation.md)；本文以下保留此前提示词生成实验及其失败边界，不作为新版运行时的完整说明。

## 应用行为

`search_policy` 返回相关片段时明确标记 `answerability=not_assessed`。每个引用增加 `citation` 标签、可直接复制的完整 `quoted_citation` 及原始片段的 `text_sha256`；无有效证据时标记 `insufficient`，检索故障仍返回原结构化错误。新增字段兼容原 `schema_version=1` 与现有证据卡。

API、CLI 与评测共享的提示词要求：逐问核对结论、条件、例外、起算点和费用承担者；部分有据则只回答有据部分，明确剩余缺口。不能把质量问题运费规则移用于无理由退货，不能以主题相似代替答案证据。检索故障、版本冲突、未生效或空返回时，不凭常识补写店铺政策。

有依据的结论紧邻 `【文件名｜小节｜版本】「实际原文内容」`。工具给出完整 `quoted_citation`，模型逐字复制，减少拼装标签、换引号或复制占位文字的错误；旧工具没有完整引用时继续使用已有标签和来源，不编造版本。完整原文复制会增加工具返回长度，单独报告实际 token 与费用。

这是模型行为约束，不是运行时语义保证。`rag.citations` 只校验来源身份、版本、正文哈希和原文摘录；允许引文空白变化，不允许改数字、条件或文字。合法引文也可能被错误解读，需要另行核对结论支持关系。

## 独立生成验收

新增 `--suite rag-grounding`，固定 13 个场景，当前 scorer 为 `rag-grounding-2`，fixture 为 `policy-answer-support-1`。首轮 v1 原判分与[清单](../reports/rag/20261019-grounding-v1-manifest.json)保留，`--suite rag-grounding-v1` 可继续使用原规则；最终使用单独冻结的 [v2 清单](../reports/rag/20261019-grounding-v2-manifest.json)：

| 类别 | 场景 |
|---|---|
| 有据回答 | 七天退货完整条件、质量问题期限和运费、退款起算点和原路退回、现价与历史快照 |
| 例外 | 定制商品虽满足天数、完好条件也不适用无理由退货 |
| 部分覆盖 | 回答退货期限，明确地址与电话缺口 |
| 主题相关但证据不足 | 退货仓库联系方式、无理由退货运费、保修年限 |
| 阻断状态 | 生效版本重叠、检索故障、政策失效、相似度未达阈值 |

每例使用实际政策原文、独立临时 ERP 数据库和完整写工具面，AutoDeny 兜底。每例固定片段范围，查询如何改写均不触发额外嵌入；标量向量仅用于控制命中或空返回，冲突 / 失效 / 故障通过明确 fixture 产生。**这是受控检索条件下的真实生成测试，不是新一轮真实向量召回测试。** 实际查询文本和完整响应仍记录在 trace。

冻结 case 包含问题、类型、片段范围、引用要求、条件断言和受限错误模式，整体纳入 `case_sha256`。报告另外记录 corpus、全部 fixture、scorer、检索模式、源码、种子、重试与请求截止；strict 对照缺任一必要指纹即拒绝。

所有助手可见文本均参与断言。检查包括成功完成、先检索、预期检索状态、有效原文引用、关键条件与已知错误模式、禁止写工具请求和所有数据库表零变化。原文引用必须来自本例工具实际返回的片段，并与冻结语料对应；不能借用上一例、旧版本或不存在的引用。

固定断言不覆盖任意自然语言矛盾，因此实际验收还需由开发代理逐条核对：回答是否对每个问题给出支持或缺口、引用是否支持附近结论、例外及条件是否被遗漏、是否补造未覆盖的政策。自动 PASS 不单独称为通用语义准确率。脚本化模型只证明 harness 接线，不计真实模型成功率。

逐条复核由本次 Codex 开发代理阅读实际输出完成，属于开发过程复核，不是独立人类评审或第二模型盲评。首轮发现的无引用支持数值、未证实流程与时区省略均单列失败；两个措辞误伤保留原自动 FAIL，不通过修改 scorer 重判。后续指引要求只用本轮片段、不扩写数值 / 流程、缺口直接说明，按原样保留必要的带时区时间；阻断状态不换关键词重复检索。

v1 保修正则会误伤“没有规定保修期为一年”的正确拒答。v2 保留问题和证据范围，改用显式区分否定语境的已知年限断言检查；按句子、逗号及转折重置语境，避免先拒答再承诺年限的矛盾答复绕过检查。测试覆盖两类已观察误伤、带空白数值、额外年限和拒答后的肯定陈述。这仍是固定断言，不能宣称通用语义判断。v1 原 case 哈希再次校验一致，v2 使用新 case 哈希与 scorer，strict 不跨版本拼接结果。

完整 `quoted_citation` 由工具先将空白规范成单行，保留全部文字、数字和标点；正文 `text` 及其哈希保持原始格式。这样避免多段 Markdown 引用在原文内部插入 `>`。引用校验仍只允许空白变化，并支持原文内的嵌套引号；英文引号替换、占位引文、改数字或改条件继续失败。

## 运行

```powershell
$env:LLM_MODEL = 'glm-5.3-flash'
uv run python -m evals --suite rag-grounding --budget 0.06 --budget-currency CNY --timeout 60 --gate configs/evals/rag-grounding.json
$env:LLM_MODEL = 'deepseek-v4.1-flash'
uv run python -m evals --suite rag-grounding --budget 0.03 --budget-currency USD --timeout 60 --gate configs/evals/rag-grounding.json
```

多次运行共用一个独立批次累计额度，后续调用仅使用剩余额度；上例为初始额度示意，实际续跑须读取[账本](../reports/acceptance/20261019-grounding-live-batch-01.json)余额。本批为完成格式修复与明确版本的拒答判分修复，已在后续调用前说明并记录 CNY 上限从 0.06 增至 0.08；USD 上限 0.03 保持不变。每次请求总截止 60 秒，SDK 与整轮重试均为 0，缺失 usage 停止整个新批次。所有额度是请求前累计估价熔断，单次响应可能超出余额，不是供应商硬额度。历史冻结预算与已完成 B4 / B6 批次不重开。

离线检查进入普通 pytest，CI 不自动增加付费运行；真实结果与人工复核另行保存。现有 baseline、B4、B5、B6 case / scorer 与历史结果均不改判。
