# ADR-0013：真实 API 默认开启受约束语义预览

- 状态：已接受并实施
- 日期：2026-11-04
- 依据：用户明确要求收尾并默认开启；创建/修改真实专项通过，业务权限由应用持有。

## 决策

1. 真实 API 共享 `bootstrap.build_live_app`，默认 enforce + semantic；离线演示显式 off。
   低层工具工厂保留原默认值，独立 CLI/MCP 不隐式新增付费候选。
2. 模型仅提出候选，来源逐字段校验、商品与目录绑定，完整表单保存和审批是独立动作。
3. 默认预算仅限制候选；保留显式 `SemanticSettings(include_business=True)` 的旧统一计量模式，
   供历史实验回归使用。缺价目、额度或 usage 异常只降级候选，不中断普通聊天。
4. 候选截止时间短于解析工具外层时限；仅 `resolve_order_items` 使用候选时限 + 5 秒，
   其他工具仍为30秒，不将人工审批等待计入执行时间。
5. 原120条数据和历史待审表冻结。用户随后委托AI完成逐条审核，当前为AI审核完成，
   无用户待审项，见[审核记录](../label-review.md)。启用标准不伪造人工金标，不据小样本宣称通用准确率。

## 取舍

可编辑预览已由程序控制来源、版本和执行权限，因此以可演示性和可验证约束完成交付。
人工金标作为扩大模型语言覆盖范围的质量依据。预算标识持久化、不自动轮换，未知费用可追溯。
本决策更新 ADR-0011 的默认关闭约定，历史验收及失败不重写。
