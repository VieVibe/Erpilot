| 用例 | 保留 clarify 的原因 |
|---|---|
| core-065，02件 | 数学上可表示2；当前规则只接受无前导零正整数，不自动规范化 |
| core-068，两十件 | 可能指二十，当前规范中文数词语法不接受这一写法 |
| core-070，一万件 | 含义明确为10000；中文数词解析只支持1..9999，可改用10000件或表单 |
| core-076，鼠标 | 即使目录只有一个包含鼠标的名称，仍要求完整商品名或SKU，不按模糊排名代选 |
| core-080，同一SKU两处数量 | 不猜累计、覆盖还是纠正，禁止暗自合并重复SKU |
| core-120，修改并删除一行 | 两个要求可理解，但本轮修改语法不支持删除，禁止只执行受支持的部分 |

备注里的命令作为原文保留，不执行；条件/否定与动作逐一核对；重名商品、冲突预算、
不存在的行、缺件数和不支持的包装单位均不能靠猜测推进。空备注字符串与清空为null分别保留。
