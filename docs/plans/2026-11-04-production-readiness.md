3. **最小身份权限**：显式启用的本地账号、登录退出、会话 / 草稿归属、审批权限与操作人审计。认证由服务端强制，资源 ID 不能替代授权；覆盖跨用户、只读角色、失效登录与审批重放。容器演示默认要求账号，不交付公网匿名写入入口。

## 技术范围

- 使用现有 Python / FastAPI / SQLite / PostgreSQL / React；身份使用标准库密码派生与随机服务端会话，浏览器使用 HttpOnly cookie。密码通过管理命令交互创建，源码和 Compose 不放默认密码。
- 最小角色：操作员（只读业务、准备自己草稿）与审批员（拥有执行自己会话写审批的权限）。本轮不提供跨用户代审批、组织管理、租户和完整 RBAC。
- 保留本机离线演示和测试注入路径。认证关闭仅供可信本机；对外绑定需显式部署配置，默认容器端口仍映射回环。
- 数据量与检索规模保持现状；不迁移业务库、不加入向量数据库、消息队列或多 worker。
